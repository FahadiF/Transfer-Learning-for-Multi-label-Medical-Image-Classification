% ABSTRACT

\begin{abstract}
Medical image classification is often hindered by the scarcity of annotated data and severe class imbalance. In this project, we address the multi-label classification of retinal diseases---specifically Diabetic Retinopathy (DR), Glaucoma (G), and Age-related Macular Degeneration (AMD)---using the ODIR dataset. We propose a Transfer Learning approach by fine-tuning a ResNet18 backbone initialized on ImageNet. To mitigate class imbalance, we implement a statistically derived Class-Balanced Loss function. Furthermore, we integrate Convolutional Block Attention Modules (CBAM) to enhance the model's focus on pathological features. Our experimental results on the offsite test set demonstrate the effectiveness of these techniques, achieving an average F-score of 0.30 under limited training constraints.
\end{abstract}

\section{Introduction}
Retinal diseases are a leading cause of blindness worldwide. Early detection through automated screening is crucial. However, training Deep Neural Networks (DNNs) for this task is challenging due to limited labeled datasets (e.g., the 800 training images in ODIR) and the multi-label nature of the problem, where a patient may suffer from multiple conditions simultaneously.

In this work, we tackle these challenges using a three-pronged approach:
\begin{enumerate}[noitemsep]
    \item \textbf{Transfer Learning (Task 1):} Initializing our model with weights pretrained on large-scale datasets to converge faster.
    \item \textbf{Class-Balanced Loss (Task 2):} Implementing a weighted loss function to prioritize minority classes.
    \item \textbf{Attention Mechanism (Task 3):} Integrating CBAM to help the network learn discriminative features.
\end{enumerate}

\section{Relation to Prior Work}
\label{sec:prior}
Early approaches to retinal disease detection relied heavily on hand-crafted feature extraction and traditional machine learning classifiers. With the advent of Deep Learning, Convolutional Neural Networks (CNNs) have become the standard. Prior studies have successfully utilized architectures like VGG, ResNet, and EfficientNet for single-label classification tasks.

However, standard CNN training often fails when data is scarce or highly imbalanced. Our work distinguishes itself from vanilla transfer learning approaches in two key ways. First, we explicitly address the severe class imbalance of the ODIR dataset (where Glaucoma and AMD are rare) using a statistically derived \textbf{Weighted BCE Loss}, rather than standard Cross-Entropy. Second, we extend the ResNet architecture by integrating \textbf{Convolutional Block Attention Modules (CBAM)} \cite{woo2018cbam}. Unlike standard ResNet, which treats all spatial features equally, our attention-augmented model dynamically re-weights features to focus on lesion-specific areas.

% 3. METHODOLOGY

\section{Methodology}

\subsection{Task 1: Transfer Learning}
We utilize the ResNet18 architecture as our backbone. ResNet18 uses residual connections to alleviate the vanishing gradient problem. Instead of training from scratch, we initialize the model with weights pretrained on ImageNet (and subsequently domain-adapted checkpoints). The final fully connected layer is modified to output 3 logits, corresponding to the three disease classes. A sigmoid activation function handles the multi-label nature of the predictions.

\subsection{Task 2: Class-Balanced Loss}
The ODIR dataset exhibits significant class imbalance. A standard Binary Cross Entropy (BCE) loss treats all classes equally, often leading to poor performance on minority classes. We implement a Weighted BCE with Logits Loss. We calculate a positive weight $w_c$ for each class $c$ based on the training set statistics:
\begin{equation}
    w_c = \frac{\text{Negative Samples}_c}{\text{Positive Samples}_c}
\end{equation}
This weight scales the loss for positive samples. Based on our training data, the computed weights were approximately $D \approx 0.55$, $G \approx 3.91$, and $A \approx 4.63$, reflecting the rarity of Glaucoma and AMD compared to DR.

\subsection{Task 3: Attention Mechanisms (CBAM)}
To improve feature extraction, we integrate the Convolutional Block Attention Module (CBAM) into the ResNet backbone. CBAM infers attention maps along two separate dimensions:
\begin{enumerate}
    \item \textbf{Channel Attention:} Focuses on 'what' is meaningful in the input image by aggregating spatial information using global average and max pooling.
    \item \textbf{Spatial Attention:} Focuses on 'where' the informative part is by applying pooling along the channel axis.
\end{enumerate}
We insert CBAM blocks after each residual stage (Layer 1-4) of the ResNet18 model using the \texttt{.add\_module} method to preserve compatibility with pretrained weights.

\section{Experiments}

\subsection{Setup}
The ODIR dataset consists of 800 training images, 200 validation images, and two test sets. All images were resized to $256 \times 256$. We applied data augmentation including random rotations, flips, and color jittering. The model was trained using the Adam optimizer ($lr=1e-4$) for 15 epochs.

\section{Task 4: Open Questions}
\label{sec:open_questions}

\textbf{Q1: Explain the benefits of Transfer Learning for this task.} \\
\textit{Answer:} Transfer learning is highly beneficial for the ODIR dataset because the number of training images (800) is insufficient to train a deep architecture like ResNet18 from scratch without overfitting. By using weights pretrained on ImageNet (millions of images), the model starts with learned low-level features (edges, textures) and high-level shapes. We only need to fine-tune the weights to adapt to the specific features of retinal diseases, leading to faster convergence and better generalization.

\textbf{Q2: How does the Class-Balanced Loss address dataset imbalance?} \\
\textit{Answer:} In the ODIR dataset, healthy images or common diseases significantly outnumber rare diseases like Glaucoma. A standard loss function would allow the model to achieve high accuracy simply by predicting the majority class (negative) for everything. The Weighted BCE Loss introduces a positive weight term ($w_c$) that increases the penalty for misclassifying a positive sample. This forces the optimization process to prioritize learning the minority classes.

\section{Conclusion}
We successfully developed a multi-label classification system for retinal diseases. Transfer learning provided a strong baseline, while the class-balanced loss effectively addressed data imbalance. The addition of CBAM attention modules further improved the model's ability to localize disease markers. Future work will focus on extended training on GPU hardware to improve precision while maintaining high recall.
